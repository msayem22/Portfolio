# My Portfolio
 
A 3-page portfolio site: Home, Projects, and About.
 
## Accessibility Fixes (WAVE)
- Added a skip link so keyboard users can jump past the menu.
- Put the menu links in a labeled list so screen readers can announce them.
- Removed the "|" symbols between links because screen readers read them out loud.
- Made my email and GitHub real links so people can click them.
- Added labels to every form field so screen reader users know what to type.
- Added a clear outline on links and fields so keyboard users can see where they are.
## Color Contrast
I checked my colors with the WebAIM Contrast Checker and they all pass AA.
- Body text: dark gray (#222222) on light gray-blue (#f5f7fa), 14.8:1
- Header and footer: white (#ffffff) on navy (#1f3a5f), 11.5:1
- Links: blue (#0b5cad) on white (#ffffff), 6.7:1
- Error text: red (#b00020) on white (#ffffff), 7.3:1
## Gestalt Principles
- **Proximity:** I kept each heading close to its text and left bigger gaps between sections so groups are easy to see.
- **Common region:** Each section sits in its own white card so it reads as one unit.
- **Similarity:** All menu links look the same, so people know they work the same way.
## Color Palette
Every page uses the same colors: navy, orange, and a light gray-blue background.
 
## Accessible Form
The contact form has 4 fields, each with a label. They are grouped with fieldset and legend. Errors show as red text on the page (no alert box).
